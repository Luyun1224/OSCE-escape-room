# OSCE ESCAPE｜臨床解碼：最後一班值勤

The Last Shift — A Clinical Mystery

## 開發範圍
Phase 1 是可通關的病史與認知推理原型。3D 建築走廊與診察空間外殼可運行，診察室目前以空間探索熱區及臨床面板代替完整醫療場景。尚未達成高擬真 3D 病人／診察室成品標準，不以此版本宣稱醫療模擬正式完成。

## 畫面規劃
首頁：深海軍藍與低飽和醫療綠，走廊為實際 WebGL 場景，左側品牌與開始／繼續／說明，右側空間資訊。新遊戲面板選擇暱稱、身分、模式與難度。
遊戲：左上任務、右上提示／倒數，下方證據與筆記工具列，中央可見探索熱區。面板開啟時保留可辨識背景。
報告：四個本關可觀察能力指標；其餘兩項明示未評量，不捏造六項成績。

## 第一關完整流程
1. 新值勤 → 探索病歷夾（身份與主訴）與工作站（安全警示）。
2. 病人自我介紹取得同意 → 解鎖現病史、相關症狀與背景病史。
3. 疼痛特徵解鎖陰性病史；背景病史解鎖用藥過敏。各分支可自由返回，對話可重讀。
4. 十項線索自動加入背包並記錄來源／時間；可標記已判讀、自由記筆記。
5. 推理板將發作、疼痛與伴隨症狀列為支持；將陰性病史列為不能單獨排除急症的限制。危險因子可作背景，不將其當確診。
6. 提出疑似急性冠心症的問題表述並確認立即評估、求援、監測、心電圖。錯誤可修正，沒有 Game Over。
7. 檢核必要線索與推理條件 → 完成時間固定 → 回饋、事件記錄、匯出／重玩。第二關僅解鎖標記，尚不可遊玩。

故事模式提供三階段引導；挑戰模式標準 12 分鐘／進階 8 分鐘，最多三次提示，逾時仍可完成；評核模式不提供提示、提交失敗只提供一般完成性回饋，通關後顯示解析。進階模式隱藏未取得線索名稱。時間不計能力分數。提示次數不減分。

## 素材清單與授權
現有：自行建立的建築空間（牆、地板、天花板、門框）、Lucide 圖示（ISC 授權，依套件 LICENSE）、自行編寫的虛構病史與低音環境音。無第三方醫療 GLB 或臨床照片。
待補：合法授權寫實急診診察室、病床、成人病人、工作站、監視器、聽診器、PBR 紋理與環境反射 HDRI；取得時逐一記錄作者、來源、版本、授權、署名與商用／修改權。人物表情與姿態須醫學教師確認。不得用基本幾何拼湊醫療器械或人體代替正式模型。
目前替代：病人使用文字身份與分支對話，不提供假操作動畫；醫療設備使用資訊面板。尚無 AO 後製或環境反射 HDRI；正式模型到位後再依裝置分級加入。現有陰影與燈光不是完整高擬真效果的宣稱。

## 教學審核
病例全為虛構，狀態「待教師審核」。參考 2021 AHA/ACC 胸痛評估指引與 2023 ESC ACS 指引。使用情境為病史與風險辨識，無處方、實際治療演算法或參考值。正式上線前由臨床教師逐項審核病例、標準解、對話、權重與語意，記錄審核者、日期與版本；未通過前不得對外宣稱經驗證。
分數為觀察項目完成率：病史 45%、推理 30%、安全 15%、溝通整合 10%；可於 case.ts 調整，尚無教師設定 UI。無正式 EPA 層級換算。提交通關後才產生報告；未完成紀錄仍留存本機事件中。

## 後續階段
Phase 1 素材提升：審核與授權模型、完整診察室、焦點圈定、無障礙對話焦點管理、裝置效能驗證、教學試測。
Phase 2：依序加入身體檢查熱區與教師審核媒體、檢驗證據配對、明確狀態機急救決策、心電圖認知流程排序（非手部技能評量）、SBAR 交班。共用病例狀態、角色、線索與事件 schema，不先做空的六關。
Phase 3：教師教案與量規版本管理、研究同意與去識別化匯出、具登入與權限的獨立後端。正式個資及多人評量不得存公開 Pages。
